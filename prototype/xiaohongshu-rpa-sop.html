影刀采集小红书公开样本，导出 Falcon 可导入 CSV

这份原型按“照着点”的方式组织：每一步告诉你影刀里大概找什么指令、建什么变量、怎么检查。目标不是大规模抓取，而是每天 50-100 条公开样本，给 Falcon 做需求分析和日报。

1

新建影刀应用/流程

先建一个专门流程，后面所有变量和元素都放在这里。

  1. 打开影刀，点“新建应用”或“新建流程”。
  2. 名称建议写：Falcon_小红书公开样本采集。
  3. 在主流程里先保留一个清晰入口：主流程.flow。
  4. 确认顶部能看到“运行/调试”，左侧能搜指令，下方能看到“元素库/运行日志/数据表格”。
检查点：点运行不会报错；现在流程可以什么都不做，只要能启动。

UI 叫法可能是

  • 新建应用 / 新建流程 / 新建项目
  • 指令区 / 指令库
  • 元素库 / 元素面板
  • 运行日志 / 日志
2

准备关键词列表

这里你看到的 list_instance 就是新建列表后的默认变量名，建议改成 keywords。

  1. 添加“新建列表”，保存对象到 keywords。
  2. 连续添加“列表插入一项”，往 keywords 插入搜索词。
  3. 先放 3-5 个词，跑通后再加，不要一开始铺太大。
  4. 创建数字变量：max_posts_per_keyword = 10，max_comments_per_post = 3。
检查点：运行到这里，打印 keywords 能看到关键词列表。

推荐关键词

小红书封面 小红书标题图 笔记没人看 AI头像 活动海报
3

打开小红书网页

影刀负责打开网页和操作公开页面，Falcon 不直接抓网站。

  1. 添加“打开网页”，可能叫“打开浏览器/打开网页(web)”。
  2. URL 填 https://www.xiaohongshu.com。
  3. 把网页对象保存到 xhs_page。
  4. 加一个“等待”动作，建议 5-10 秒，让页面加载完。
检查点：影刀运行后能打开小红书首页。遇到登录、验证码、访问限制，停止。

安全边界

  • 不教绕过登录限制。
  • 不处理验证码。
  • 不做高频刷新。
  • 不自动触达用户。
4

对每个关键词搜索

用 ForEach 列表循环，让影刀依次搜索每个关键词。

  1. 添加“ForEach列表循环”，循环对象选 keywords。
  2. 当前项保存到 current_keyword。
  3. 在循环内：点击搜索框，输入 current_keyword，再按 Enter。
  4. 每个关键词搜索后等待 5-10 秒，可低频滚动 1-2 次加载结果。
检查点：每轮循环后，页面搜索词应该变成当前关键词，并出现公开搜索结果。

频率建议

  • 每天总样本 50-100 条。
  • 每个词先采 10 条以内。
  • 两次搜索之间保留等待。
  • 跑通之前只用 1 个关键词。
5

获取搜索结果帖子列表

核心动作是“相似元素列表”：让影刀识别一批结构相近的帖子卡片。

  1. 在左侧搜“相似元素”，优先找“获取相似元素列表(web)”或“循环相似元素(web)”。
  2. 捕获页面上两个相似的帖子卡片或标题元素。
  3. 如果是“获取相似元素列表”，保存到 post_cards，再 ForEach 循环。
  4. 如果是“循环相似元素”，当前循环项保存到 current_card。
检查点：循环里打印 current_card 的文本，能看到不同帖子标题或摘要。

常见叫法

  • 获取相似元素列表(web)
  • 循环相似元素(web)
  • 获取网页对象列表
  • 相似元素操作
6

提取帖子标题、摘要、链接、发布时间

每个帖子卡片写一行 source_type=post。

  1. 用“获取元素信息(web)”从 current_card 取文本，先存到 card_text。
  2. 如果能定位标题子元素，用“获取关联元素(web)”取标题，保存到 post_title。
  3. 链接通常取标题或卡片链接元素的 href 属性，保存到 post_url。
  4. 发布时间能取就存 post_time，取不到留空。
  5. 组装一行：xiaohongshu, current_keyword, post, post_title, post_summary, post_url, post_time。
检查点：post 行至少要有标题或内容。链接最好有，方便后续去重和人工复核。

空值处理

  • 标题缺失：允许，但 content 要有。
  • 时间缺失：允许，留空。
  • 链接缺失：可以导入，但不推荐。
  • 标题和内容都空：Falcon 会跳过。
7

可选：进入详情页提取公开评论

评论不是必需项；只取页面自然展示的前几条公开评论。

  1. 点击当前帖子卡片，进入详情页或新标签页。
  2. 等待页面加载，遇到限制提示直接关闭详情页。
  3. 用“循环相似元素(web)”捕获评论文本。
  4. 最多取 max_comments_per_post 条，建议 1-3 条。
  5. 评论行的 source_type 写 comment，标题沿用 post_title。
检查点：comment 行的 content 是评论正文，url 是原帖子链接。

不要做

  • 不深翻评论。
  • 不展开隐藏评论。
  • 不批量进入用户主页。
  • 不自动评论、私信或关注。
8

把每一行写入 Excel 或数据表格

推荐先用影刀“数据表格”，稳定后再接 Excel。

  1. 先写表头：platform,keyword,source_type,title,content,url,published_at。
  2. 每采到一条 post 或 comment，就组装 row_data。
  3. 用“写入内容至数据表格”或“写入内容至Excel工作表”。
  4. 写入方式选“追加一行/行写入”。
  5. 写入前做去重：post 用 post_url，comment 用 post_url + comment_text。
检查点：表格第一行是英文表头，每行固定 7 列。

9

导出或另存为 CSV

编码优先 UTF-8 或 UTF-8-SIG，避免中文乱码。

  1. 如果用数据表格，找“导出数据表格”或“数据表格导出”。
  2. 如果用 Excel，保存为 CSV UTF-8。
  3. 文件名建议：xiaohongshu_falcon_YYYY-MM-DD.csv。
  4. 导出后用文本编辑器打开，确认中文正常、逗号分隔、表头正确。
检查点：第一行必须是英文表头。Falcon 支持 UTF-8-SIG，所以 Excel 带 BOM 的 CSV 也能读。

用 Falcon 验证 CSV

先用 template 模式验证，不需要真实 API key。

  1. 进入项目目录：/Users/zhanglongsheng/Documents/Falcon。
  2. 运行初始化、导入、分析、日报四条命令。
  3. 看终端输出：Imported ... unique items 和 Wrote reports/daily-report.md。
  4. 打开 reports/daily-report.md 检查结果。
检查点：日报里能看到关键词表现、推荐选题和触达任务箱。

验证命令在右侧

macOS 和 Windows PowerShell 都已放在右侧速查区，可以直接复制。

真实 CSV 接入顺序： 先用 1 个关键词采 10 条以内，导出 CSV 后跑 Falcon 四条验证命令；确认导入和日报正常，再扩大到 5 个关键词、每日 50-100 条公开样本。

排查清单

  • 导入少：Falcon 会按 platform + url + title + content 去重。
  • 中文乱码：导出 CSV UTF-8 或 UTF-8-SIG。
  • 标题缺失：可留空，但 content 不能空。
  • 评论缺失：跳过 comment 行即可。
  • 登录墙/验证码/限制：停止，不处理。

合规边界

  • 只采公开可见内容。
  • 每日先采 50-100 条样本。
  • 不绕过平台限制。
  • 不自动评论、不自动私信。
  • Falcon 只导入、分析、生成日报和草稿。
