# 小红书影刀采集工作流草案

本草案只使用 `ShadowBladeElement` 截图中已经可见的影刀指令名称。未在截图中出现的具体指令不会写入正式链条，只会列为待补截图。

架构原则见 [影刀 RPA 混合架构开发指南](yingdao-hybrid-architecture-guide.md)。后续编排默认采用“可视化负责交互与元素捕获，Python 代码段负责清洗和组装”的混合架构；详情页优先走点击卡片和 SPA 弹窗路径，不批量直接跳转 URL。

## 当前可编排准流程

```text
0. 初始化关键词列表
   - 使用：数据处理 > 列表操作 > 新建列表
   - 输出：keywords
   - 使用：数据处理 > 列表操作 > 列表插入一项
   - 插入：小红书封面 / 小红书标题图 / 笔记没人看 / AI头像 / 活动海报

1. 打开网页
   - 使用：网页自动化 > 打开网页
   - 目标：打开小红书公开网页
   - 输出：网页对象，暂定 xhs_page

2. 等待页面加载
   - 使用：等待 > 等待 或 等待 > 等待元素(web)
   - 目标：降低频率，等待页面稳定

3. 循环搜索词
   - 使用：循环 > ForEach列表循环
   - 循环列表：keywords
   - 当前项：current_keyword

4. 输入搜索词
   - 使用：网页自动化 > 点击元素(web)
   - 使用：网页自动化 > 填写输入框(web)
   - 可选：鼠标键盘 > 键盘输入
   - 目标：把 current_keyword 输入到搜索框
   - 依赖元素：搜索框元素，尚未截图归档

5. 等待搜索结果
   - 使用：等待 > 等待
   - 使用：等待 > 等待元素(web)
   - 可选：条件判断 > IF 网页包含
   - 可选：条件判断 > IF 元素可见(web)
   - 依赖元素：结果卡片或结果列表元素，尚未截图归档

6. 获取帖子卡片列表
   - 使用：相似元素操作 > 获取相似元素列表(web)
   - 或使用：相似元素操作 > 循环相似元素(web)
   - 目标：得到搜索结果里的帖子卡片集合
   - 依赖元素：搜索结果帖子卡片相似元素，尚未截图归档

7. 循环帖子卡片
   - 使用：循环 > ForEach列表循环
   - 或使用：循环 > 循环相似元素(web)
   - 当前项：current_card

8. 提取帖子字段
   - 使用：网页自动化 > 元素操作 > 获取关联元素(web)
   - 使用：网页自动化 > 数据提取 > 获取元素信息(web)
   - 标题输出：post_title
   - 摘要输出：post_summary
   - 链接输出：post_url
   - 时间输出：post_time
   - 依赖元素：卡片标题、摘要、链接、时间元素，尚未截图归档

9. 组装 CSV 行
   - 使用：数据处理 > 列表操作 > 新建列表
   - 使用：数据处理 > 列表操作 > 列表插入一项
   - 输出：row_data
   - 行字段：platform, keyword, source_type, title, content, url, published_at
   - 推荐升级：外层先声明 `row_data_list`，循环内用 Python 代码段清洗字段并 `row_data_list.append(row)`，循环结束后统一落盘

10. 写入数据表格
   - 使用：数据表格 > 写入内容至数据表格
   - 写入字段：platform, keyword, source_type, title, content, url, published_at

11A. 导出 CSV
   - 使用：数据表格 > 数据表格导出
   - 编码要求：UTF-8 或 UTF-8-SIG

11B. 直接写 CSV
   - 使用：数据处理 > CSV读写 > 数据写入CSV
   - 编码要求：UTF-8 或 UTF-8-SIG
   - 说明：如果影刀数据表格导出不好控编码，可改用此路径

12. 日志与人工检查
   - 使用：其他 > 打印日志
   - 使用：其他 > 添加备注说明
```

## 可选评论链条

```text
1. 点击当前帖子卡片
   - 使用：网页自动化 > 点击元素(web)
   - 依赖元素：当前帖子卡片或详情入口元素，尚未截图归档
   - 注意：优先绑定循环变量 `current_card`，不要在循环内回到静态元素库节点

2. 等待详情页评论区
   - 使用：等待 > 等待元素(web)
   - 依赖元素：评论文本元素，尚未截图归档
   - 注意：如果点击后只是 SPA 弹窗和地址栏变化，继续使用原 `web_page` 对象，不新建网页对象

3. 获取评论相似元素列表
   - 使用：相似元素操作 > 获取相似元素列表(web)
   - 或使用：相似元素操作 > 循环相似元素(web)

4. 循环评论
   - 使用：循环 > ForEach列表循环
   - 使用：网页自动化 > 数据提取 > 获取元素信息(web)
   - 输出：comment_text

5. 写入 comment 行
   - platform = xiaohongshu
   - keyword = current_keyword
   - source_type = comment
   - title = post_title
   - content = comment_text
   - url = post_url
   - published_at = comment_time 或空

6. 关闭详情弹窗
   - 使用：鼠标键盘 > 键盘输入
   - 输入：`{Esc}`
   - 目标：回到搜索结果页继续下一张卡片
```
