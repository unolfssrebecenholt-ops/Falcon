Use case: ui-mockup
Asset type: high-fidelity desktop UI style reference for Falcon Agent local workbench, 1536x1024.
Primary request: Create a controlled-color UI direction for Falcon Agent. It should keep the neutral, orderly, premium structure of V1 while adding richer semantic state color only where it helps decisions.
Product context: Falcon Agent is a local-first browser collection, analysis, content operations, and human-confirmed execution workbench. It is a serious production tool used daily.
Visual direction: objective, comfortable, premium product UI. Clean neutral app shell with carefully limited color accents. The interface should feel calmer and more coherent than a colorful admin dashboard.
Palette: neutral off-white background (#F6F7F9), white surfaces, cool gray sidebar (#EEF1F5), deep blue-gray text (#17202A), secondary text (#5C6675), neutral borders (#D9DEE7). Use controlled accent colors only in small areas: cobalt blue for primary action and selected state (#4D7CFE), sky blue for info/collection (#34A7D8), cyan/blue-teal for analysis (#28A9B7), warm amber for pending/review (#D89A36), soft coral for risk/paused (#E36F61), muted sage for ready/success (#6FA77D). Do not use dark blue, dark green, dark red, bright red, purple, magenta, emerald, or large teal/green surface washes.
Layout: Falcon 控制台 desktop app shell. Compact top bar, sober neutral left navigation rail, dense but breathable main dashboard. Show page header “仪表盘”; badges “LOCAL”, “GPT-5.5”, “人工确认”; four compact KPI tiles; left panel “今日待办”; right panel “链路入口”; lower table “最近采集与分析”; right status rail “队列健康”.
Color rules: no colored icon on every navigation item. Only selected nav gets a quiet cobalt tint. KPI tiles may have small colored icons. Status chips use pastel fills. Buttons are mostly neutral, with one primary cobalt button and at most one amber/coral action visible in each module. Keep the majority of the screen neutral.
Component style: crisp 1px neutral borders, 6-8px card radius, no nested cards, no large drop shadows, no glassmorphism, no decorative blobs, no side-stripe accents, no oversized hero typography.
Typography: system sans, compact hierarchy, professional dashboard scale, no huge hero type, no negative letter spacing. Chinese labels should be legible and must not overlap.
Camera/framing: straight-on desktop screenshot mockup, full UI visible, no fake browser chrome, no device frame, no marketing illustration, no people, no 3D, no abstract decoration.
Quality constraints: production-grade UI mockup, calm but expressive, clean spacing, stable alignment, realistic data density, no unreadable text, no random English filler, no text overflow.
