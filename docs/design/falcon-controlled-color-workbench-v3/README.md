# Falcon Controlled Color Workbench V3

## 目的

这版修正 V2 的问题：V2 把颜色分散到太多组件，导航、按钮、状态和图标同时抢注意力，导致界面变乱。V3 回到 V1 的秩序感，只在决策点使用更丰富的轻量状态色。

## 设计规则

- 导航保持中性，只给当前项一个浅蓝选中态，不给每个菜单项分配彩色图标。
- KPI 可以有小面积轻量色图标，但卡片背景和边框保持中性。
- 按钮只分三类：主按钮钴蓝、普通按钮中性、少量风险/待处理按钮使用柔和珊瑚或琥珀。
- 状态 chip 使用浅填充和低饱和文字，颜色不超过必要状态。
- 队列健康使用小点和浅色标签，不铺大色块。
- 避免深蓝、深绿、深红、大红、紫色和大面积青绿。
