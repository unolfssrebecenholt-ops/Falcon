采集中心

多平台入口统一管理，但第一阶段只把小红书做深。每个任务必须能回答三个问题：跑到哪一步、为什么停住、从哪份证据继续排查。

采集运行链路

Python 负责调度和入库，Node sidecar 只负责真实浏览器执行，并持续回传事件。

visual first
01 core Falcon Python Core 创建 run、写入队列、接收事件、触发分析。
02 queue Collection Run run id、平台、账号、关键词、进度和恢复点。
03 sidecar Node Playwright 多进程执行器，管理浏览器动作和平台 adapter。
04 browser Profile Session 账号隔离、真实窗口、人工登录和风控确认。
05 store Evidence Store items.jsonl、events.jsonl、截图、资产和诊断包。
