Use case: ui-mockup
Asset type: high-fidelity desktop UI style reference for Falcon Agent local workbench, 1536x1024.
Primary request: Create a second visual direction based on the neutral Falcon workbench, but with richer color language for states, buttons, and icons while avoiding heavy or loud colors.
Product context: Falcon Agent is a local-first browser collection, analysis, content operations, and human-confirmed execution workbench. It is a serious production tool used daily.
Visual direction: restrained neutral product UI with richer semantic accents. The UI should feel objective, comfortable, precise, and premium, not decorative or marketing-like.
Palette: neutral off-white background (#F6F7F9), white surfaces, cool gray secondary surfaces, deep blue-gray text (#17202A), secondary text (#5C6675). Use accent colors only in controlled small areas: medium cobalt for primary actions (#4D7CFE), sky blue for collection/info (#34A7D8), clean cyan/blue-teal for analysis (#28A9B7), warm amber for pending/review (#D89A36), soft coral for risk/paused/destructive warnings (#E36F61), muted sage for success/ready (#6FA77D). Do not use dark blue, dark green, dark red, bright red, purple, magenta, mint-wash backgrounds, emerald sidebars, or purple gradients.
Layout: Falcon 控制台 app shell with compact top bar, sober left navigation rail, dense but breathable main dashboard. First viewport should show: page header “仪表盘”, small context badges “LOCAL”, “GPT-5.5”, “人工确认”; four compact KPI tiles; a left workflow panel “今日待办”; a right panel “链路入口”; lower table/list “最近采集与分析”; and a slim status rail for queue health.
Color usage: navigation category icons should use different soft accents; selected nav item uses a light cobalt tint. KPI tiles can have tiny colored icons and top hairlines, not large colored backgrounds. Buttons should include primary cobalt, secondary neutral, info sky-blue outline, warning amber, and soft coral risk action. Status chips should be pastel fills with readable colored text. Keep the total color area moderate.
Component style: crisp 1px neutral borders, 6-8px card radius, no nested cards, no large drop shadows, no glassmorphism, no decorative blobs, no side-stripe accents, no oversized hero typography. Buttons are compact rectangles with 6px radius.
Typography: system sans, compact hierarchy, professional dashboard scale, no huge hero type, no negative letter spacing. Chinese labels should be legible and must not overlap.
Mood: objective, controlled, audit-friendly, comfortable for daily operations, more expressive than V1 through semantic accent colors only.
Camera/framing: straight-on desktop screenshot mockup, full UI visible, no fake browser chrome, no device frame, no marketing illustration, no people, no 3D, no abstract decoration.
Quality constraints: production-grade UI mockup, clean spacing, stable alignment, realistic data density, polished state colors, no unreadable tiny body text, no random English filler, no text overflow.
