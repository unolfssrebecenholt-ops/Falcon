# Falcon Design References

This directory keeps the current design reference and the immediately previous reference for comparison:

- `falcon-layout-redesign-v2/`: latest bright glass-tech full workbench prototype, including dashboard, collection, analysis, review, execution, tasks, and desktop/mobile screenshots.
- `falcon-layout-redesign-v1/`: previous full workbench prototype, retained for visual comparison.

Older one-off prototypes and historical screenshot batches were removed to keep the repository small and easier to navigate. Use Git history if an older visual direction is needed for comparison.
